# Support

Hitchcock AI Job Review Kit is alpha software maintained on a best-effort basis.

## Before opening an issue

1. Confirm you are using Python 3.11+ and Node.js 22.13+.
2. Run the Python tests and `npm run verify:release` from `dashboard/`.
3. Check that the Python API is running on `127.0.0.1:8765` and the dashboard is using
   `http://localhost:5173`.
4. Reproduce the problem with the synthetic files under `examples/`.

## Safe issue reports

Include the expected behavior, actual behavior, operating system, runtime versions, and a
minimal synthetic reproduction. Redact candidate names, emails, resume content, decisions,
employer correspondence, local paths, API keys, and database contents.

Security issues should follow [SECURITY.md](SECURITY.md) and must not be reported publicly.

## Scope

The project does not provide recruiting, immigration, legal, or career-placement advice.
It also cannot guarantee that a posting is current, complete, legitimate, or available in a
specific jurisdiction. Always verify details on the employer's official application page.
